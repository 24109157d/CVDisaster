## 3 改进一：局部训练直接区分困难候选

全局参数的训练集合与局部模块的训练集合分别管理。局部训练使用三类错误候选：

1. 全局分数高的错误候选，训练局部纠正全局容易出现的错误。
2. 局部分数高的错误候选，减少局部在融合时增加的错误。
3. 随机错误候选，保留不同地点之间的基本区分能力。

对每个训练查询，以该轮全局训练图库检索得到的前 20 个候选作为主要困难候选范围。使用配对 ID 排除正候选。局部分数在这一范围内寻找局部高分错误候选，无需对训练图库的全部图片组合执行候选交互。

局部损失的一个训练列表固定为 12 张：1 张正确图片、4 张全局高分错误图片、4 张局部高分错误图片、3 张前 20 之外的随机错误图片。全局候选与局部候选去除重复，继续按相应分数顺序选取剩余图片，保证列表中 ID 唯一。反向检索独立构造相同规则的训练列表。

原有每轮训练集特征提取时，在同一次 ConvNeXt 前向中缓存全局向量及进入新增投影之前的局部特征。正负样本均使用同一轮缓存和确定性预处理，避免将正样本在线增强特征与负样本缓存特征混合。每轮刷新缓存，记录原有参数 checkpoint 标识和用于局部候选选择的新增模块标识。

缓存保存为 FP32，编码器提取过程仍执行原有 AMP。FP32 存储保留该次前向的数值，不将它解释为编码器改为 FP32 运算。测试缓存同样保存进入新增投影之前的特征，使新增参数更新后能够重新计算局部分数。

每个 epoch 完成原有全局训练与该轮全局评价、检索、best 判定和 shuffle 后，固定本轮全局参数和缓存，执行一轮新增模块训练，再读取同轮测试缓存完成融合评价。新增模块训练 batch 为 64 个查询，查询 ID 和顺序采用本轮全局训练实际使用的清单。新增 optimizer 的计划 step 数与该轮全局图像 batch 数一致，混合精度跳过更新时分别记录计划和实际更新数。

本轮全局前 20 个候选由本轮全局缓存确定。每个新增训练 batch 开始时，使用当前局部参数对该 batch 查询的前 20 个候选评分，排除正确图片与已选全局困难候选，再选择局部分数最高的 4 个错误候选。后续 batch 使用已经完成前序更新的局部参数重新评分与选择。两个检索方向分别处理。

前 20 个候选的局部分数保留梯度，候选选择使用其 `detach` 结果，选中分数继续用于 `L_local`，有效查询的全部前 20 个分数同时用于 `L_fusion`。前 20 之外的随机候选，以及未进入前 20 的正确图片，补充计算分数。正候选始终为局部列表首项，列表保持 12 个唯一 ID。训练前的初始化评价只记录结果，不增加新增 optimizer step。

两个方向分别使用独立的 `random.Random`，seed 为 `seed+2*epoch` 和 `seed+2*epoch+1`，仅用于新增模块的随机负候选。每轮候选记录保存缓存标识、初始局部参数 SHA256、随机 seed，以及每个 batch 更新前的局部 step、查询 ID 和实际候选 ID。候选选择不改变原 geo 的采样、随机状态或 scheduler。

下一轮全局训练继续原有参数、optimizer、scheduler、GradScaler 和已完成的全局 shuffle 状态。局部训练不更新这些状态，也不重新选取原有全局训练 batch。

局部候选选择不改变原有全局训练 batch、顺序或 scheduler。新增模块按对应查询 ID 读取缓存，执行自己的损失计算和参数更新。四个、四个、三个的候选数量属于设计取值，已有 16 个查询的诊断没有证明这些数量最优。

## 4 改进二：保留中间层与最后一层的空间信息

共享 ConvNeXt 保持原有前向与全局输出，额外读取两个 stage 的输出：

| 来源 | 街景预期形状 | 卫星预期形状 | 新增投影 |
|---|---|---|---|
| `stages[2]` | `[B,512,8,48]` | `[B,512,24,24]` | 512 到 64 通道 |
| `stages[3]` | `[B,1024,4,24]` | `[B,1024,12,12]` | 1024 到 64 通道 |

两层均执行 `detach`。中间层聚合到最后一层的空间尺寸，分别投影后拼接，每个位置为 128 维。街景保留 `4×24`，共 96 个位置；卫星保留 `12×12`，共 144 个位置。空间形状在实现时使用真实图片核验。

缓存存储聚合后的未投影特征，保证通道投影仍然接受训练。训练与测试均保存为 FP32，记录原前向 AMP 设置、形状和 checkpoint 标识，其数值影响需要检查。

这种设计增加局部模块能够读取的信息，不保证中间层信息必然提高检索。相同匹配结构下的最后一层输入与双层输入比较，用于辨别其贡献。

各位置加入图片内归一化坐标的 `MLP(2,32,128)` 编码，隐藏层激活为 ReLU，街景与卫星各有一个 128 维视角 embedding。网格中心坐标定义为 `x=2*(column+0.5)/width-1`、`y=2*(row+0.5)/height-1`。坐标表示图片内位置，不表示真实地面距离。

## 5 改进三：候选对交互与允许未匹配的区域

街景和某张卫星候选的局部特征经过两组 `self-attention` 与 `cross-attention`，共四层，通道数 128，heads 为 4，FFN 隐藏维度 256，dropout 为零。同一层在两个视角之间共享参数，两边更新均读取更新前的输入。

这四层采用 Pre-LayerNorm。每层分别对 attention 分支和 FFN 分支的输入执行独立的 `LayerNorm(128,eps=1e-5,elementwise_affine=True)`，随后执行分支计算并与输入进行残差相加。对于当前视角特征 X 和对应的 attention 来源 Y：

\[
X_1=X+\operatorname{MHA}(\operatorname{LN}_{attn}(X),\operatorname{LN}_{attn}(Y),\operatorname{LN}_{attn}(Y)),
\]

\[
X_2=X_1+W_2\operatorname{GELU}(W_1\operatorname{LN}_{ffn}(X_1)).
\]

self-attention 使用 `Y=X`，cross-attention 使用另一视角更新前的特征。FFN 为 `Linear(128,256)`、GELU、`Linear(256,128)`，两层 Linear 使用 bias；残差相加后不追加 LayerNorm。每个 attention 层具有自己的参数，只有该层的两个视角共享参数。

上述 Pre-LayerNorm、eps `1e-5` 和 FFN GELU 仅规定新增局部 attention 的行为。原有 ConvNeXt 的 LayerNorm eps `1e-6`、卷积后归一化顺序、原 MLP GELU 及全局 head 均继续使用第 2 节的结构。

输出经过共享 `Linear(128,128)` 和逐位置 L2 归一化，得到 `f_i` 与 `h_j`。位置匹配分数为：

\[
A_{ij}=f_i^\top h_j/\tau_{match},\qquad \tau_{match}=0.1.
\]

矩阵为 `96×144`，加入一行、一列 dustbin 后为 `97×145`。新增位置使用可训练 `bin_score`，初值 1。一般情况下，增广传输矩阵 `P` 的目标边缘为：

\[
a=(\underbrace{1,\ldots,1}_{M},N),\qquad
b=(\underbrace{1,\ldots,1}_{N},M),\qquad M=96,\ N=144.
\]

先以 `a/(M+N)`、`b/(M+N)` 在对数域求解，再乘以 `M+N` 得到 `P`。真实位置之间的矩阵记为 `W=P[:M,:N]`。各真实位置分配给其他真实位置的权重允许小于 1，其余权重进入 dustbin。

FP32 求解至少执行 30 次，每增加 10 次检查当前计算组全部候选对，最多 500 次。相对各自目标边缘的最大绝对行列误差均不超过 `1e-3` 时结束，检查包含 dustbin。达到上限使用当前有限矩阵继续计算，记录未收敛数量；非有限值立即报错。

dustbin 提供拒绝匹配的表达能力，图片配对监督不提供真实局部对应。网格数量不同、感受范围重叠和视角差异也限制几何解释，因此矩阵仅作为检索内部变量，不将分配总量直接解释为真实可见面积。

## 6 改进四：局部分数同时读取内容与支持总量

每个候选对汇总以下两个 128 维特征：

\[
v_{diff}=\frac{\sum_{ij}W_{ij}|f_i-h_j|}{\min(M,N)},\qquad
v_{prod}=\frac{\sum_{ij}W_{ij}(f_i\odot h_j)}{\min(M,N)}.
\]

分母使用固定位置数量，匹配总量减小时，汇总特征保留这种变化。额外计算六个统计量：

- 匹配总量 `m=sum(W)/min(M,N)`。
- 平均行最大真实匹配权重 `q_g`。
- 平均列最大真实匹配权重 `q_s`。
- 按真实匹配总量加权、按 `log N` 归一化的行条件熵 `H_g`。
- 按真实匹配总量加权、按 `log M` 归一化的列条件熵 `H_s`。
- 双向一致性 `c`。

其中 `r_i=sum_j W_ij`、`t_j=sum_i W_ij`、`R_ij=W_ij/(r_i+epsilon)`、`C_ji=W_ij/(t_j+epsilon)`，`epsilon=1e-8`。

\[
H_g=\frac{\sum_i r_i[-\sum_jR_{ij}\log(R_{ij}+\epsilon)]}
{(\sum_i r_i+\epsilon)\log N},\qquad
c=\frac{\sum_{ij}R_{ij}C_{ji}}{\min(M,N)}.
\]

列条件熵使用对应的列方向定义。统计量在数值误差范围内核验其有限性和数学范围，保留原始诊断值。

拼接得到 262 维证据，经过 `MLP(262,64,1)`，隐藏层激活为 ReLU，末端使用 tanh，输出 `s_l`，范围为 `[-1,1]`。该评分模块通过候选的配对 ID 学习局部证据与正确地点的关系。

低熵、高匹配总量或高一致性都不能单独证明对应正确。图片配对损失可能无法唯一确定 dustbin 的使用方式；需记录匹配总量、分数区分度和实际纠错数量，不强制将负图片对的全部区域分配给 dustbin。

## 7 改进五：独立局部损失与最终融合损失

原有全局 `L_global` 继续直接调用原 InfoNCE，batch 为 64，label smoothing 为 0.1，原 `logit_scale` 参与原有参数学习。

局部损失针对第 3 节的困难候选列表计算交叉熵，每个查询的正确图片为目标，双向分别平均：

\[
L_{local}=\tfrac12\left[
\operatorname{mean}_q\operatorname{CE}_{0.1}(s_l(q,C_q)/\tau_{local},y_q)
+\operatorname{mean}_{q'}\operatorname{CE}_{0.1}(s_l(q',C_{q'})/\tau_{local},y_{q'})
\right],\qquad \tau_{local}=0.07.
\]

融合训练使用各方向全局前 20 个候选，统一计算 `s_f=0.6*detach(s_g)+0.4*s_l`，并使用 `CE_0.1(s_f/tau_fusion,y)`，其中 `tau_fusion=0.05`。正确图片进入集合的查询参与该方向融合损失；未进入的查询继续参与独立局部损失，记录未进入数量。两个方向分别计算固定比例融合分数，使用各自的交叉熵，再取平均得到 `L_fusion`。某方向没有有效查询时，该方向融合项定义为零。

两个新增损失温度是固定常量，与原全局 `logit_scale` 分别管理，不接受梯度。新增训练接口不接收原全局温度；原温度继续仅按原 `L_global` 学习。`tau_match=0.1` 单独控制匹配矩阵生成，与两个损失温度分别记录。推理直接使用 `0.6s_g+0.4s_l`，不按分支分别除以损失温度，保持固定 40% 的评分定义。

温度取值参考已有模型的 [无参数更新诊断](diagnostics/4309752_temperature_diagnostic.json)。该诊断使用测试集 Top-20 分数，能够说明固定分数的损失与梯度变化，不能证明重新训练后的最优温度。两个温度与候选刷新方式同时改变，本次完整实验评价其共同作用，各项独立贡献需要分别比较。

对于正确图片 `p` 和错误图片 `n`，融合纠正顺序的条件为：

\[
\beta[s_l(p)-s_l(n)]>(1-\beta)[s_g(n)-s_g(p)].
\]

独立局部损失学习候选区分能力；融合损失训练局部评分，使其在固定 `0.4` 比例下改善最终排名。对于全局错误候选，其分数差需要满足 `0.4*[s_l(p)-s_l(n)]>0.6*[s_g(n)-s_g(p)]`。局部分数稍微高于错误候选，并不一定足以纠正全局分数差。

原有参数使用 `L_global`，新增参数使用：

\[
L_{new}=\lambda_lL_{local}+\lambda_fL_{fusion}.
\]

设计参考值为 `lambda_l=0.5`、`lambda_f=0.5`。这表示两项训练目标的系数相同，相对比例为 1:1。它们不表示预测时全局与局部各占 50%，也不表示两项梯度大小必然相同。

| 参数部分 | 梯度来源 |
|---|---|
| ConvNeXt、原全局 head、原 `logit_scale` | `L_global` |
| 局部投影、位置编码、attention、匹配与评分模块 | `lambda_l L_local + lambda_f L_fusion` |
| 固定融合比例 `0.4` | 常量，不接受梯度 |

在独立 AdamW 中，将两个系数同时从 1 改成 0.5，主要对新增模块的总梯度进行相同比例缩放。Adam 的一阶、二阶矩归一化会大幅抵消恒定共同缩放；epsilon、梯度裁剪、混合精度与非有限更新判定等仍可能造成差别。因此不能将两个 0.5 理解为新增参数更新必然减半，也不能将其作为原有参数的保护机制。

本方案保护原有参数的机制是梯度路径、采样过程与优化过程独立。损失系数的主要待检验问题是 `lambda_l:lambda_f` 如何平衡局部能力和最终排序目标。

## 8 改进六：固定比例融合与纠错评价

训练、评价和推理中，全部查询及其前 20 个候选统一使用固定比例：

\[
\beta=0.4,\qquad
s_f(q,s)=0.6\operatorname{detach}(s_g(q,s))+0.4s_l(q,s).
\]

固定 `0.4` 同时用于 `L_fusion` 和最终排名，训练目标与推理分数保持一致。融合模块执行常量加权，不设置门控 MLP 或可训练的 `fusion_logit`。局部投影、位置编码、attention、部分匹配与评分模块继续通过 `L_local`、`L_fusion` 学习。

局部模块读取共享 ConvNeXt 的空间特征，但其损失不更新 ConvNeXt、原全局 head 或原 `logit_scale`。新增模块的作用包括学习困难候选的局部区分能力、输出候选对匹配分数，以及通过融合分数改变最终排序和 Top-1 图片。原全局图像采样继续使用全局特征，局部困难候选用于新增模块自身的训练。

公共非负比例保持两个分支一致认可的候选顺序。局部与全局判断不一致时仍可能增加错误，因此同时统计纠正数量与新增错误数量。

推理使用完整图库的全局向量选择前 20，再对这些候选执行局部交互和固定比例融合，在集合内部重新排序，其余候选保持全局顺序接在后面。卫星侧缓存独立投影特征，候选对 attention 输出需针对具体查询计算。正确图片未进入前 20 的查询仍计入完整评价，最终 R@1 受本模型全局 R@20 限制。

评价使用与原 geo 相同的 1,649 个查询和 1,649 张卫星图片，沿用相同预处理、配对 ID、完整图库分母及 Recall 定义。R@1% 使用 `floor(1649/100)=16`。全局前 20 是重新排序范围，未进入该范围的查询仍参与全部指标统计。相同的评价规则允许比较两种检索方法；新增局部计算的时间、显存和缓存开销单独报告。

固定 `0.45`、`0.5` 作为后续单独比较的比例。使用同一 checkpoint 修改推理比例时，记录为推理比较；使用相应固定比例计算训练融合损失时，记录为独立训练实验。两种比较分别报告，不将推理比较的成绩作为相应训练方案已经取得的成绩。

除 R@1、R@5、R@10、R@1% 外，报告全局错误中被纠正的数量、全局正确中新增错误的数量、两者净差，以及全局分支自身的相同指标。原 Recall 的严格大于定义保持一致，另记录同分数量及固定 ID 顺序的 Top-1 结果，防止无区分分数影响解释。

## 10 小型 CPU 实验能够判断哪些损失系数问题

无参数更新时，改变 `lambda_l`、`lambda_f` 不会改变模型预测或 accuracy。已有 `4300142` 的融合比例检查不能确定训练损失系数。

使用真实模型和训练图片，无更新 CPU 检查可以分别测量新增参数上的 `g_l=grad(L_local)`、`g_f=grad(L_fusion)`，记录范数、余弦相似度、按模块的大小，以及不同相对系数下合成梯度的方向。融合比例保持 `0.4`，仅比较新增评分参数的损失梯度。

比较相对系数时固定系数和，例如 `(0.25,0.75)`、`(0.5,0.5)`、`(0.75,0.25)`。这能够筛查某项梯度过大或目标方向冲突，不能证明哪个比例的最终 accuracy 更好。原有 `4294316` 测量的是旧模型共享 ConvNeXt 梯度，不能替代新结构新增参数上的测量。

若需要比较训练后的准确率，必须让新增参数发生更新。可以在小型训练特征缓存上固定全局参数与输入特征，对相同新增模块初始状态、相同更新次数和相同样本分别使用上述系数，使用独立查询 ID 检查候选排名、纠错和新增错误。这属于小规模新增模块训练，不能称为无更新测验。短程结果也只能用于筛查，不能确定完整训练的最优系数。

作业 `4309752` 提供相同局部结构的训练后 checkpoint，可用于分析现有局部分数和新增参数梯度。固定 `0.4` 融合训练尚未执行，两个损失系数也尚无独立训练比较。任何随机初始化新模块的梯度只能用于检查数值与路径，不作为训练后最佳系数的证据。

新增模块的本地数值测试包含明确数值输入上的梯度与优化步骤，用于核验实现，不构成 CVIAN 训练实验。已有训练作业见作业记录，损失系数的独立 CPU 实验未安排。诊断结果按用途保存在 `diagnostics/`，作业参数和成绩保存在 `records/`。

## 11 对照、验收与记录

已有 `3979539` 为直接全局基线，`4277758`、`4290487` 为完整旧结构的结果参考。新结构的主 checkpoint `best_fusion` 按融合测试 R@1 选择，其全局和局部指标在同一 checkpoint 上记录。独立保存按原全局测试 R@1 选择的 `best_global`，以及最终完整模型 `last`。

`best_global` 保存原有参数和原全局指标，用于与复现 geo 的最佳结果比较。`best_fusion` 保存同一轮全局和新增参数。两者最佳轮次可能不同，分别报告轮次；同一轮全局指标与复现的对应轮次比较，区分训练变化与 checkpoint 选择的影响。评价完整模型时使用同一完整 checkpoint，不混合不同轮次的全局与新增参数。

固定 `0.4` 为本方案的正式融合比例，按该比例选择主 checkpoint。同一 checkpoint 的其他比例比较保持候选集合相同，完整记录全部预定比例的成绩。作业 `4309752` 的固定 `0.3`、`0.4` 结果作为已有预测比较，固定 `0.45`、`0.5` 按单独任务安排；固定 `0.4` 尚不能认定为最优设置。

针对六项设计，分别规定必要的归因问题：双层输入与仅最后一层输入、困难候选与随机候选训练、带 dustbin 与真实矩阵完全分配、完整证据评分与仅匹配平均分、独立局部与融合目标、不同固定比例的作用。每项比较保持其他设置一致，实际执行哪些训练以单独任务记录为准，本方案不自动提交这些作业。

验证内容包括：

- 原有初始化、全局前向、损失、原参数梯度、采样顺序和优化规则；辅助损失对原有参数无梯度；新增非有限梯度不改变原有 GradScaler 判定。逐项核验原参数梯度及单步 AdamW 状态、全部学习率与更新步数、每轮样本 ID 和原随机状态；数值差异记录环境、容差和实际误差。

- attention 的同步双向更新、`97×145` 增广矩阵、真实与 dustbin 边缘、FP32 数值与停止规则。
- 262 维评分输入、六项统计量、两项独立损失及加权梯度，训练与推理均采用常量 `0.4`；新增 Pre-LayerNorm、FFN GELU 和 MLP ReLU 的作用范围，以及原 ConvNeXt LayerNorm 和 GELU 的结构一致性。
- 候选对分组和 activation checkpointing 的实际分数与梯度、两个方向的目标索引、有效查询集合与完整候选数量。
