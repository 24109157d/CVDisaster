# 合并实验1结果文件

这些文件为已完成作业输出的原样副本，保留原始配置、环境、权重SHA256和服务器路径。模型权重和图片保存在超算。

| 目录与文件 | 用途 |
|---|---|
| `4308780/result.json` | 完整串联评价、分组准确率、分类报告和统计检验 |
| `4308780/predictions.csv` | 全部1,649张查询的检索图片、真实标签及两种卫星输入下的类别和概率 |
| `4308780/est_metrics.json` | Est best轮次、200轮训练完成状态和配对图片分类指标 |
| `4323061/diagnosis.json` | 5组CPU分支检查、权重变化和原GPU概率差异 |
| `4323061/input_checks.json` | 全部333组卫星文件SHA256和输入张量差异 |

`paired`表示地面查询图加数据集配对卫星图片，`combined`表示同一张地面查询图加Geo检索的卫星图片。两种条件使用同一Est best，真实标签均取地面查询图标签。

Geo检索错误的333组输入中，三个类别概率发生变化，最终预测类别全部相同。这个结果说明本次best对这些检索替换不敏感，尚不能据此确认地面分支相对卫星分支的依赖程度。
