# 运行说明

## 依赖与输入

使用 Python 3.10、`requirements.txt` 中的 TensorFlow 2.10.1、TensorFlow Addons 0.18.0 及其余版本。模型直接使用 `tf.keras.applications.ConvNeXtTiny`。

`config.json` 的 `data_root` 指向完整 CVIAN；`initial_weights` 指向官方 `convnext_tiny_notop.h5`。文件 SHA256 必须为 `d547c096cabd03329d7be5562c5e14798aa39ed24b474157cef5e85ab9e49ef1`。程序不会自动下载或替代缺失权重。

依赖、原始图片和权重缺失时直接终止。以下命令均从本实验目录执行，输出目录必须为全新目录。正式训练和评价入口检查 Slurm 计算节点环境；本轮仅编写代码和执行本机检查，没有提交任务。

## 固定清单

```bash
python prepare.py --metadata "$CVIAN_ROOT/02_Position/CVIAN_position.geojson" --est-train "$EST_REFERENCE/est_train_60.csv" --est-test "$EST_REFERENCE/est_test_60.csv" --est-config "$EST_REFERENCE/est_config.json" --output "$MANIFEST"
```

`EST_REFERENCE` 指向复现 EST 作业 `4087311` 的输出目录。服务器路径为 `/scratch/liuzeyu/heyinxi/runs/est-4087311/Author CVDisaster/disaster_perception_mapping`。该目录提供 seed=626、6:4 的实际训练及测试清单。程序检查参考配置、原始清单 SHA256、4,121 个唯一目标、类别及顺序，生成 train、validation、refit、test 和各自的邻图清单。

完整训练集合为 2,472 个目标，测试集合为 1,649 个目标。完整训练集合内部按 Sequence、seed=626 和 20% 分组比例，生成 1,971 个训练目标及 501 个验证目标。本机清单位于 `.local-cache/manifest-est626/`，参考文件位于 `.local-cache/est-reference-4087311/`。训练、评价及多种子入口检查清单中的全部划分参数与配置一致。

## 选择与重训

```bash
python train.py --manifest "$MANIFEST" --variant full --seed 42 --stage select --output "$SELECT_RUN" --gpus 2
python train.py --manifest "$MANIFEST" --variant full --seed 42 --stage refit --selection-run "$SELECT_RUN" --output "$REFIT_RUN" --gpus 2
```

当前唯一模型入口为 `full`。选择阶段按独立验证 accuracy 选取 epoch；重训阶段从相同 ImageNet 权重初始化，使用完整训练集合训练选定轮次。两个阶段均以 200 epochs 为 cosine 调度总目标。

`--resume-from` 指定具有 `latest/current.json` 的已有产物，并为本次执行提供全新 `--output`。恢复检查配置、划分、源码、TensorFlow 版本、权重结构与 optimizer steps。恢复模型、门控进度、优化器和选择状态；Dropout 随机流没有保存，恢复过程不承诺逐位相同。

## 多种子执行

```bash
python pipeline.py --manifest "$MANIFEST" --seeds 42 626 2024 2025 2026 --output "$PIPELINE_RUN" --gpus 2
```

每个种子分别执行选择、重训、评价，写入 `runs.json`，随后执行配对统计。五个种子使用相同的 seed=626 清单。`--defer-statistics` 保留预测，推迟统计；可以合并不同训练种子的索引。

## 评价与统计

```bash
python evaluate.py --run "$REFIT_RUN" --manifest "$MANIFEST" --output "$EVALUATION_RUN" --gpus 2
python analysis.py --run-index "$RUN_INDEX" --output "$STATISTICS_RUN" --repetitions 10000 --group sequence
```

评价仅接受完成的重训产物，核验 checkpoint、清单和源码指纹。测试期间固定权重，全部条件重新执行完整前向计算。条件包括 paired、wrong、noise、gaussian、zero；后面三种表示均匀噪声、Gaussian Noise 和像素全零。

`--geo-predictions` 接受包含 `sample_id`、`retrieved_satellite`、`true_satellite`、`true_label` 的已有 Geo 清单。程序检查完整测试目标、真实卫星与类别，并报告 Geo 检索错误子集。

`predictions.csv` 保存 `prediction`、`base_prediction`、`p0..p2`、`base_p0..base_p2`，以及目标、种子、卫星来源、噪声指纹和分组。`result.json` 保存每种条件的 Base/Final 分类指标及整体和各类别净收益。

默认统计比较 Final/Base，以及 paired 分别相对 wrong、noise、gaussian、zero。Base 是同一个模型的无邻图增量输出。它参与相同模型的训练，不能解释为独立训练的无邻图模型。

自定义 `--comparisons` JSON 指定 `name`、`family`、`left`、`right`。两侧指定 `files`、`condition`，可选 `prediction_column`；默认读取 `prediction`，基础输出指定 `base_prediction`。`subtract` 支持差值之差。

`Nfixed`、`Ncorrupted`、`delta_N` 为逐种子整数计数。随机替换条件先对五组输入平均，其正确性可以为小数；此类配对比较的整数计数记为 null。配对统计报告 OA/Macro-F1 差值、区间、分组置换 p 值及同族 Holm 校正。

## 本机检查

```bash
python -m pytest -q
python validation_cases.py --manifest "$MANIFEST" --data-root "$CVIAN_ROOT" --weights "$CONVNEXT_WEIGHTS" --output "$CASES_JSON"
python verify_model.py --cases "$CASES_JSON" --variant full --output "$VERIFY_RUN" --gpus 0
```

pytest 使用真实固定清单及历史真实预测。`EST_TEST_MANIFEST` 可指定相同划分的清单目录。模型验证使用完整输入尺寸与真实训练图片，检查前向、门控预热、熵梯度截断、邻图顺序、空邻图、重复内容、有序损失、卫星替换、反向传播和检查点恢复。

`scripts/run.sbatch`、`scripts/verify.sbatch` 仅保存作业定义。代码状态、已经执行的检查及尚未验证的范围见本机检查记录。
