# 运行说明

## 依赖与数据

使用 Python 3.10、TensorFlow 2.10.1 和 TensorFlow Addons 0.18.0，版本要求见 `requirements.txt`。`config.json` 中的训练种子固定为 `seed=626`。

通过 GitHub 同步代码后，在超算实验目录执行 `bash scripts/prepare_assets.sh`，准备官方 `convnext_tiny_notop.h5` 和 pyproj 3.6.1 离线 wheel。权重 SHA256 必须为 `d547c096cabd03329d7be5562c5e14798aa39ed24b474157cef5e85ab9e49ef1`。

数据划分直接读取复现 EST 作业 4087311 的 `est_train_60.csv`、`est_test_60.csv` 和 `est_config.json`，检查原始指纹，保持 2,472 个训练目标与 1,649 个测试目标的内容、类别和顺序。完整训练集合内部按 Sequence、seed=626 选取 1,971 个训练目标和 501 个验证目标。

## 提交入口

本机执行数据、统计、Python 语法及 Shell 语法检查。检查通过后，提交并推送 GitHub；超算执行 `git pull --ff-only` 并核验完整提交号。

从超算仓库根目录提交唯一作业：

```bash
bash 'ME CVDisaster/est_experiment_1/scripts/submit.sh' <完整提交号>
```

作业申请两张 GPU、8 个 CPU、60,000 MiB 内存，时限 5 天。输出目录为 `/scratch/liuzeyu/heyinxi/runs/est-experiment-1-<JobID>/`，日志为 `/scratch/liuzeyu/heyinxi/logs/est-experiment-1-<JobID>.log`。

提交入口核验当前 Git 提交，使用 `--export=NIL`，通过脚本参数传入完整提交号。作业内明确设置 Python、动态库和任务缓存路径。启动日志首行为 `EST_JOB_START`，包含 JobID、seed 和源码提交号。

XLA 使用 `/software/nvidia/cuda/11.6/bin/ptxas` 编译 GPU 指令，作业启动时检查执行权限并打印版本。作业缓存中的 CUDA 目录同时提供该编译工具和 EST 环境的 `libdevice.10.bc`，通过 `PATH` 与 `XLA_FLAGS` 指定。动态库继续从 EST 环境读取，TensorFlow 保持 2.10.1。

同一个作业依次执行：

1. 从明确的 Git 提交提取源码，配置已有 CUDA 的 XLA 目录，离线安装 pyproj 到该作业缓存。
2. 核验复现 EST 清单，生成固定划分及各集合自身的邻图索引。
3. 使用真实图片检查模型前向、梯度累计、双 GPU 镜像更新、检查点恢复及五种卫星条件的数据读取。
4. 使用 seed=626 执行独立验证选择、完整训练集合重训和固定测试集合评价。
5. 在同一个作业内计算 Base/Final 净收益、卫星替换差值、分组置信区间及置换检验。

脚本采用 `set -euo pipefail`，任何步骤失败都会终止当前作业。GPU 前向和反向检查在作业启动后执行。正式训练从配置的 ImageNet 权重重新初始化。

## 产物

- `manifest/`：固定目标及邻图清单。
- `cases.json`、`verification/`：真实验证输入和检查结果。
- `output/full/626/select/`：独立验证选择及检查点。
- `output/full/626/refit/`：完整训练集合重训产物。
- `output/full/626/evaluation/`：同权重模型在各输入条件下的逐图预测及指标。
- `output/statistics/`：配对分组统计。

训练只使用正确配对卫星。评价使用同一个 checkpoint，包含 paired、wrong、noise、gaussian、zero；输入替换仅执行前向计算，模型参数保持固定。CSV 保存 Base/Final 概率、目标 ID、真实标签、输入条件、训练种子和分组。

## 单独执行程序

以下程序供复核使用，作业脚本已按顺序调用：

```bash
python -m pytest -q
python pipeline.py --manifest "$MANIFEST" --output "$OUTPUT" --gpus 2
```

`pipeline.py` 从配置读取 `seed=626`，完成验证选择、重训、评价和统计。训练及评价入口核验固定清单、配置、源码和权重指纹。输出目录必须为全新目录。

`train.py --resume-from` 可以明确指定具有 `latest/current.json` 的完整轮次产物，并提供全新 `--output`。恢复时核验配置、数据、源码、TensorFlow 版本、权重结构及 optimizer steps；Dropout 随机流没有保存。
